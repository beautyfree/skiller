Not sure which Mac? Check Apple menu → About This Mac.
“Chip” means Apple silicon; “Processor” means Intel.

Choose the installer for your computer from the latest Skiller release on GitHub. Installation steps are below.

Install on your Mac

  1. Open the disk image

    Open the downloaded .dmg file from your Downloads folder.

  2. Drag into Applications

    Drag Skiller onto the Applications folder in the window.

  3. Open Skiller

    Open Skiller from Applications. Confirm the macOS prompt to open the downloaded app.

Install on Windows

  1. Open the installer

    Open the downloaded .exe file in Downloads. This build is for Intel / AMD 64-bit Windows.

  2. Follow the setup steps

    Follow the installer’s prompts. If Windows shows a security warning, check the publisher and file before continuing.

  3. Launch Skiller

    Open Skiller from the Start menu and explore your skill library.

Install on Linux

Linux builds are for Intel / AMD 64-bit computers. Choose the format that fits your distribution.

  1. Download the AppImage

    Save the AppImage from the latest release.

  2. Allow it to run

    In your file manager, open the file’s properties and enable execution as a program.

  3. Open Skiller

    Double-click the AppImage. If it won’t launch, try the Debian package or tar archive for your distribution.

  1. Download the package

    Choose the Debian / Ubuntu build and save the .deb file.

  2. Install the package

    Open the file with your package installer and confirm installation. You may need your administrator password.

  3. Launch Skiller

    Open Skiller from your application menu.

  1. Extract the archive

    Extract the downloaded .tar.xz into a folder you’ll keep.

  2. Run the included installer

    Open a terminal in the extracted Skiller folder, then run ./install.sh. It configures the sandbox and registers a menu entry.

  3. Open Skiller

    Launch Skiller from your application menu. Keep the extracted folder in place.
